# 白玉京：本地 Codex 连接版

这是学习通油猴脚本。DeepSeek Harness 的桥接插件已在 [独立仓库 dsh_codex](https://github.com/TianSamsara/dsh_codex) 维护，两者的桥接协议与启动流程不同。

当前版本：**0.15.2**（2026-10-28）。详细变更见 [更新日志](CHANGELOG.md)。

基于提供的 Greasy Fork 脚本 0.13.2 制作。原始文件保留在 `upstream.user.js`，修改版为 `byj.user.js`。本目录原来没有项目文件。

## 使用

1. [安装 / 更新油猴脚本](https://raw.githubusercontent.com/TianSamsara/byj_xxt/main/byj.user.js)，或用本地 `byj.user.js` 替换原脚本，避免两个版本同时启用。未配置 GitHub 更新地址的旧版需先手动更新一次，后续由油猴按设置检查更新。
2. 在本机安装并打开 Codex，完成 ChatGPT 登录。在脚本 **AI 连接 → 本地 Codex → 安装／修复本地桥接** 保存随脚本内置的安装包；如果浏览器没有弹出下载，再点下方“直接保存安装包”。解压后双击里面的 `install-byj-bridge.cmd` 一次。无需下载完整仓库、安装 Git、手动安装 Node 或执行命令。默认安装到 `%LOCALAPPDATA%\BYJCodexBridge`，已有本项目的启动入口会在原目录修复，原密钥保留。浏览器中的油猴脚本无法直接启动未安装的本地程序，所以新电脑首次仍需运行这一次安装文件。
3. 安装器自动准备程序、检测 Codex、注册启动入口并启动桥接，尝试复制本地密钥。返回脚本密钥框按 **Ctrl+V** 粘贴。需要重新获取密钥时，点击“获取当前密钥”，在正在运行桥接的本机 `http://127.0.0.1:17653/setup` 页面复制后返回。以后直接点击“启动本地桥接”，允许浏览器打开启动器即可；已有密钥继续有效。
4. 点击“获取模型”，选择模型和思考强度，保存设置。已填写密钥时，启动桥接后会自动获取模型；也可随时点击“检测连接”。档位由本机 Codex 按模型返回，切换模型会重置为默认档位。浏览器第一次询问访问本机地址时允许该请求。

遇到 HTTP 401，说明正在运行的服务拒绝了当前密钥；请用“获取当前密钥”读取该服务的密钥页，替换 Key 后获取模型并保存。0.15.2 起，“复制本地密钥”只会直接复制最近验证通过的输入值；未验证、过期或被拒绝时转到当前服务的密钥页，避免反复复制旧值。每次 AI 请求读取最新保存的连接设置，已打开的作答子页面也会使用新密钥；请求开始后仍保持本次设置不变。尚未保存的输入不会用于作答。

安装文件自带六个桥接程序文件，文件逐个核对 SHA-256，不从网页执行安装命令。优先复用系统 Node 20+ 或 Codex 自带的 Node；都没有时从 Node.js 官方站点下载固定版本的便携运行组件，并同时核对官方清单和内置哈希。首次补齐组件需要联网，不修改系统 PATH、不要求管理员权限，也不依赖 Harness。

Codex 更新后，启动器会在保存路径失效时重新检测当前版本，继续使用原密钥。修复安装会备份桥接源码，核对端口进程及服务身份，再替换本项目的文件；其他进程或未知目录不会被覆盖。请在安装／修复前暂停作答；旧版桥接无法报告活动请求，新版会等待当前请求结束，启动失败尝试恢复旧源码与服务。不会改写油猴中的模型、思考强度或其他偏好。

0.15.1 起，ZIP 安装包直接随用户脚本发布，点击安装时从内置字节创建浏览器下载文件，不再请求 GitHub、不调用 `GM_download`，无需开启油猴的下载功能或下载扩展名白名单。界面只提示“已发起保存”，无法凭程序点击判断文件已经落盘；浏览器拦截自动点击时，仍保留“直接保存安装包”供手动点击。每页复用一个小文件对象，不反复创建下载资源。

本地文件下载也不可用时，可点面板中的“GitHub 备用下载”，打开 [仓库安装包页面](https://github.com/TianSamsara/byj_xxt/blob/main/install-byj-bridge.zip)；也提供 [安装包直链](https://raw.githubusercontent.com/TianSamsara/byj_xxt/main/install-byj-bridge.zip)。安装包里只有一个安装文件，移动或删除下载包不影响安装后的桥接。开发者运行 `python upgrade.py` 即会先构建安装包，再同步生成脚本、内置 ZIP 和版本元数据。

0.14.7 在 AI 连接中增加“允许联网检索（本地 Codex）”，默认开启，可取消并保存。模型按需通过 Codex 内置网页搜索查阅公开资料，题目相关搜索词会发往搜索服务，可能增加等待和额度消耗。题目明确要求检索、对比来源时，答案应保留来源标题和完整链接；普通知识题不额外要求来源数量，资料不足仍提示人工核对。日志记录实际网页工具调用次数，不把“允许搜索”等同于已成功查证。

联网检索需要更新本地项目并停止旧桥接后重新启动，单独更新油猴脚本不够。脚本会检查桥接能力，旧桥接会明确提示升级到 0.14.7+；旧客户端没有传入联网开关时仍禁用搜索。原本的模型、密钥和思考强度设置保留。

0.14.8 优化连续做题：桥接复用最多两个 Codex 进程，联网开关不同的请求分开处理，同一进程同一时刻只处理一个请求。每道题使用新的临时会话，完成后取消订阅以释放会话；不会将上一题对话传给下一题。模型目录缓存 5 分钟，手动获取模型时强制刷新，选择缓存外的新模型/档位时也会刷新；配置在进程内复用，账户类型仍逐题检查。闲置 90 秒回收进程，请求异常、超时、浏览器断开会丢弃相关进程。

AI 日志显示本题桥接总用时、准备时间、模型/检索时间及是否复用连接。联网能力检查成功后按地址和密钥缓存 15 秒；普通稳定知识题不额外检索，明确要求来源的题目仍可联网。常规题可在 AI 连接中选择低思考强度 `low` 并保存；版本升级保留你的已有选择。

本机小样本：同为 `gpt-6.1-sol`、`low`、允许联网但无需搜索的两道简单算术题，0.14.7 用时 32.9/33.4 秒，0.14.8 为 23.5/19.3 秒；第二题确认复用进程，两题合计从 66.4 秒降至 42.8 秒。仅反映此次测试，复杂题、联网和服务端排队的耗时会不同。此优化需要更新本地桥接并重启；油猴更新后可看到耗时日志。

最近验证通过的密钥可通过“复制本地密钥”使用 `GM_setClipboard` 直接复制，收到回执后才提示成功；其他情况会打开本机密钥页。“获取当前密钥”始终打开正在运行服务的密钥页，不受输入框旧值影响。保留 `GM_setClipboard`、`GM_openInTab` 授权。

本机密钥页需要 0.14.5+ 桥接，仅允许浏览器顶层导航；禁止跨站 fetch、iframe 和跨域读取，设置禁止缓存、禁止嵌入和独立 opener。页面在本机显示密钥供用户复制，不提供跨域取密钥的 JSON API。该页面无需 Windows 启动器，桥接已经运行时可直接打开。

Windows 启动器仍使用固定的 `byj-codex://start` 链接，启动已安装的桥接并尝试复制本地密钥；网页只报告启动请求，不将它当成剪贴板成功回执。不接收 URL 中的命令或密钥，不注册开机自启，无需管理员权限。安装目录移动后重新运行安装器修复入口；运行组件路径失效会自动重新检测。卸载可在安装目录运行 `./install-bridge-launcher.ps1 -Uninstall`。非 Windows 环境可继续手动运行 `node bridge.mjs`。

也可运行 `./start-bridge.ps1 -Background -CopyKey` 启动并复制密钥；剪贴板占用时会短暂重试，失败后可再次点击复制按钮。

脚本更新检查地址是本仓库的 `main/byj.meta.js`，完整下载地址是 `main/byj.user.js`；两个文件由 `python upgrade.py` 同步生成，版本保持一致。请在油猴设置中启用更新检查；具体检查频率由油猴设置决定。自动更新只更新浏览器脚本，本地组件升级可再次使用面板中的“安装／修复本地桥接”，无需手动更新文件或注册。

默认地址：`http://127.0.0.1:17653/v1/chat/completions`。本地 Codex 模式固定此地址，避免把本地密钥发送到远程。其他服务商仍按原方式填写 API Key。

桥接通过官方 `codex app-server` 接口启动独立本地进程，使用 CLI 已保存的 ChatGPT 登录状态。**仅打开 Codex 桌面窗口不等于 CLI 已登录**；如提示未登录，在终端运行 `codex login`。桥接要求账户类型为 ChatGPT，拒绝在此模式下悄悄切换成 API Key 计费。实际额度、限流、模型权限由当前账户和服务端决定，模型列表本身不保证推理权限。

不读取、复制或向浏览器发送 Codex 登录令牌；不接管当前聊天。网页题目文本及启用视觉后的图片会通过本机 Codex 发往模型服务。本地连接密钥保存在 `.bridge-token`，不要分享或提交到仓库。丢失时停止桥接、删除该文件、重启后更新油猴配置。

`CODEX_BIN` 可指定 Codex 可执行文件绝对路径；通常无需填写，安装器会查找桌面版、Store 安装和 CLI 组件。`./start-bridge.ps1`（无 `-Background`）以前台运行，按 Ctrl+C 关闭；`-Background` 在后台运行，启动日志位于安装目录的 `.bridge-work/`，不再向日志输出本地密钥。重复启动不会创建第二个服务，端口被其他服务占用时会报错。

## 已处理的问题

- 增加本地 Codex 入口、从本机接口动态获取模型，兼容原有文本/图片题请求和答案解析。
- 增加按模型能力提供的思考强度选项，并保存、校验和传递给 Codex。
- 简答/论述题与填空题分开处理，一个编辑器内可填写多段、多要点答案；填空题仍逐空校验。
- 合并同一富文本编辑器的注册别名和 DOM 节点，排除隐藏提交字段、工具栏和不可见控件，避免把一个编辑器识别为多个答题区。
- 排除包住已注册 UEditor 的 `.eidtDiv`、`.textDIV` 和 `contenteditable` 外层包装，修复日志中的 `editable:DIV, editor:edui…` 重复计数。
- 富文本校验从编辑器 HTML 保留段落与换行后读取，避免 `getContentTxt()` 合并段落导致“正文已填但内容未确认”的误报。提交字段使用相同文本规则校验，并短暂等待异步同步；正文缺失或字段未同步仍会报错。
- AI 连接界面增加本地桥接启动按钮、连接状态和检测按钮；启动后自动获取模型，错误密钥和离线状态分别提示。
- 本地请求等待上限调整为 190 秒，桥接超时为 180 秒；超时和浏览器断开会结束对应进程，最多并行两个请求。成功的请求复用空闲进程，避免每道题都重新启动和初始化 Codex。
- 仅监听 IPv4 回环地址，校验 Host、网页 Origin 和随机密钥；请求体最大 12 MiB，只接受文本和内嵌图片，拒绝本地文件路径与远程图片 URL。
- 使用临时会话、只读沙箱、禁止审批，关闭 shell、多代理并覆盖 MCP 配置；拒绝 app-server 发来的工具/审批回调。网页搜索按请求中的布尔开关单独启用，CLI 与会话配置同时生效，联网不会开放本地命令或文件访问。
- 仅返回最终答案，过滤 Codex 检索过程的 commentary 消息，避免混入答案 JSON；答案缓存区分联网开关并更新提示词版本。
- 修复获取模型期间切换服务商后旧响应覆盖新模型的问题，并限制模型列表渲染数量。
- API 地址禁止内嵌账号密码、查询参数及片段；补全 GM_info 授权。
- 缺少课程测验设置时默认不启用自动提交；已明确保存的偏好继续保留。
- 自动更新切换到本 GitHub 仓库，使用同步生成的版本元数据和完整脚本，不再从上游 Greasy Fork 覆盖更新。

## 验证

0.15.0 新增独立安装包、下载按钮和 Windows 原生安装测试；覆盖没有 Node PATH、中文空格路径、重复安装密钥保留、损坏包及未知目录保护。实测独立桥接启动后获取 7 个模型，缺少 Node 时自动下载官方便携组件并核对哈希。测试新建的桥接与用户运行中的服务隔离，未修改 Harness 插件。

运行 `npm test`，再运行 `node --check byj.user.js`。编辑器测试覆盖模拟 DOM 下的别名与祖先包装去重、隐藏字段过滤和内容同步；连接测试覆盖启动后等待、密钥错误及旧响应丢弃；复制测试覆盖空密钥打开本机页面、油猴复制回执和失败后备，以及本机页面拒绝跨域和嵌入访问。联网测试覆盖开关传递、旧桥接拒绝、来源提示词及检索过程过滤。进程池测试覆盖独占复用、策略隔离、缓存刷新、闲置回收、初始化失败，以及 HTTP 超时/浏览器断开后能继续请求。`node diagnose.mjs` 检查真实 CLI 的账户类型和模型列表；`node diagnose.mjs --smoke` 额外执行一次最小模型请求，会消耗少量额度。可加 `--effort=low` 验证所选思考档位。`node diagnose.mjs --web-smoke --effort=low` 实际检索 NASA 与 ESA 两个公开来源并检查网页搜索事件，同样消耗额度。

本次未登录学习通页面进行真实填答/提交测试。原脚本的播放器、题库、跨帧和提交逻辑主要保留，未进行完整重构；使用前请核对答案和提交设置。

## 官方接口依据

- [Codex App Server](https://developers.openai.com/codex/app-server)
- [Codex Authentication](https://developers.openai.com/codex/auth)
- [Codex 网页搜索配置](https://learn.chatgpt.com/docs/config-file/config-basic#web-search)：`live` 允许实时检索，`disabled` 关闭搜索。
- [UEditor 编辑器源码](https://github.com/fex-team/ueditor/blob/master/_src/core/Editor.js)：`getContentTxt()` 丢弃段落格式，不能直接拿来校验多段答案。

`upgrade.py` 可从保存的原始源码重建本地脚本。`schemas/` 为本机 Codex 生成的协议参考，不参与运行。
